Patient Monitoring App Frontend

The app frontend is a Java Swing desktop client, so it opens as a local desktop window instead of inside this browser page.

Keep this backend running, then launch the client from a second terminal:

cd /Users/apple/Documents/GitHub/PatientMonitoring/PatientMonitorClient PATIENT_SERVER_URL=http://127.0.0.1:8080 ./gradlew run
